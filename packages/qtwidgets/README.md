# @nodalia/qtwidgets

NDL para aplicaciones **Qt Widgets**: tokens aplanados (`nodalia-qt.json`), una plantilla de hoja de estilos (`nodalia.qss`) y las doce hojas ya rellenas (`nodalia-<modo>-<densidad>.qss`).

**En uso en Vortia 0.5.0 (Qt 6, estilo Fusion, macOS); sin probar en Linux ni Windows.** Ver [docs/integration/qt-widgets.md](../../docs/integration/qt-widgets.md). Versión `0.1.0-alpha.0`.
