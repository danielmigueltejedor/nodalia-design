# @nodalia/web

Componentes CSS sin framework y comportamientos ARIA para Nodalia Design Language.

```css
@import '@nodalia/web/nodalia.css';
```

```js
import { tabs, tree, setAppearance } from '@nodalia/web/behaviors';
```

Ver [docs/integration/web.md](../../docs/integration/web.md) y [docs/components.md](../../docs/components.md). Verificado en Chromium; Firefox y WebKit sin probar. Versión `0.1.0-alpha.0`.
