# @nodalia/tokens

Tokens de Nodalia Design Language (formato DTCG), validación y generación de CSS. Es la fuente de la que salen los demás paquetes.

```js
import { loadTokens, resolve } from '@nodalia/tokens/lib';
```

```css
@import '@nodalia/tokens/css'; /* variables --ndl-*, modos, densidades, movimiento reducido */
```

Ver [docs/tokens.md](../../docs/tokens.md). Versión `0.1.0-alpha.1` (pre-release: la API puede cambiar).
