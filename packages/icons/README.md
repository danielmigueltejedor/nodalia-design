# @nodalia/icons

Los iconos de NDL: 55 dibujos originales de trazo sobre una rejilla de 24 px. Se definen en [`src/icons.mjs`](src/icons.mjs) y se generan como SVG sueltos, *sprite* e índice.

Ver [docs/iconography.md](../../docs/iconography.md). Versión `0.1.0-alpha.1`. Licencia MIT, como el resto del repositorio.
