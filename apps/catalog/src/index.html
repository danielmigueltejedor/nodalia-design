Nodalia Design Language

Live reference for the tokens and components. Change theme, contrast, density, scale and motion above: everything below, including the demos, follows. Every control is a real element, not a screenshot.

Colour

Semantic roles, resolved for the current appearance. Components never use palette values directly.

Typography

Inter for interface text, Sora for display, system monospace for code. Fonts are not bundled in this release: the stacks fall back to system fonts.
